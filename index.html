Data Types

Data types represent the foundational data formats recognized natively by programming languages. They define how data is stored, what values it can contain, and what types of operations can be safely performed on that data structure.

main.py 
# Basic Data Types in Python
integer_var = 42          # Whole number
float_var = 3.14159       # Floating-point decimal
boolean_var = True        # Logical Truth state
string_var = "Hello"      # Text characters

print(type(integer_var))  # Output verification
