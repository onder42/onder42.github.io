FEATURED ARCHITECTURE: 8-BIT CPU EMULATOR

This hardware-software co-design project models a custom 8-bit CPU control unit, instruction register, and system bus using discrete logic simulation driven by optimized C++ microcontroller firmware.

The system executes a 4-bit Opcode / 4-bit Operand cycle mimicking classic SAP-1 computers within a 256-byte unified memory space. It bypasses standard framework overhead for explicit byte manipulation, deterministic cycle timing, and strict 8-bit datatype consistency (uint8_t).
